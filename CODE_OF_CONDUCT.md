# Code of Conduct

Inmersion-CS projects are learning spaces as well as software projects. Contributors are expected to communicate with clarity, patience, and respect.

## Expected behavior

- Discuss ideas and code rather than attacking people.
- Give specific, actionable feedback and assume good-faith participation.
- Respect differences in experience, language, background, identity, and viewpoint.
- Keep educational claims accurate and distinguish completed functionality from proposals.
- Help maintain an environment where beginners can ask questions without ridicule.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, deliberate intimidation, doxxing, or sustained personal attacks are not acceptable.

## Enforcement

Project maintainers may edit or remove contributions and restrict participation when conduct materially harms the project or its contributors. Sensitive reports should be made privately through GitHub rather than discussed in a public issue.
