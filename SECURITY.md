# Security Policy

## Supported versions

The current `main` branch is the supported development version during Foundation v0.1.

## Reporting a vulnerability

Do not open a public issue for a suspected security vulnerability. Use the repository's private GitHub security reporting channel when available. Include the affected path or component, reproduction steps, expected impact, and any safe proof-of-concept details needed to understand the report.

Please avoid accessing data that is not yours, disrupting services, or publishing exploit details before maintainers have had a reasonable opportunity to investigate.
